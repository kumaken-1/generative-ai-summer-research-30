# 30のお題と「教職員が身に付けたい7つの力」分類案

作成日：2026年7月27日  
位置付け：検討用の仮分類。実装前に内容を確認する。

## 7つの力

1. **主体性の剣**：AIに判断を任せきらず、使う・使わないを自分で決める
2. **情報守りの盾**：個人情報、校内情報、著作権、ルールを守る
3. **仕事選びの羅針盤**：AIに任せる仕事と、人が担う判断を見極める
4. **指示の魔法袋**：目的、材料、相手、形式を整理して伝える
5. **対話の杖**：追加の依頼や問い返しで、回答を近づける
6. **真実を映す鏡**：日付、数値、固有名詞、根拠などを確かめる
7. **仕上げのたい焼き**：AIの下書きを、自分の言葉や学校の実態に合わせて完成させる

## 分類の基準

- 1題につき、**主となる力を1つ、一緒に使う力を1つ**設定する。
- お題を「できたことにする」と、両方へ1ポイントずつ加える。
- 1題2ポイント、全30題で全体60ポイントとする。
- ポイントは能力の高さではなく、その力を使う体験をした回数とする。
- 安全注意が表示されるだけでは「情報守りの盾」に分類しない。写真・画像・文書・公開範囲などを具体的に確認するお題に付ける。

## 現実性の検討

### 現実的な点

- 1題につき2ポイントで固定されるため、利用者が計算方法を理解しやすい。
- 力ごとの総ポイントが違っても、`獲得ポイント / 総ポイント`で達成割合を示せる。
- 「主となる力」を表示することで、お題のねらいがぼやけない。
- 「一緒に使う力」により、生成AI活用では複数の力が組み合わさることを表せる。
- 全30題で60ポイントになり、全体インジケーターも説明しやすい。

### 注意が必要な点

- 指示の魔法袋は12点、真実を映す鏡は6点で、総ポイントに差がある。これは重要度の差ではなく、今回の30題で体験する機会数の差である。
- 情報守りの盾は全題に関係するが、ポイント対象は具体的な確認行動を含む7題に限定した。全題へ付けると分類の意味が薄くなるためである。
- 完了ボタンだけでは、本当に二つの力を使ったかを外部から確認できない。ポイントは能力評価ではなく、本人が「手順を試した」と記録する自己申告とする。
- 主となる力と一緒に使う力を別配点にすると複雑になるため、どちらも1ポイントとする。
