# 会話履歴の説明文 修正仕様

作成日：2026年7月28日

## 目的

初心者が「生成AIは会話を恒久的に記憶している」と誤解しないよう、同じ会話内の文脈利用を正確に説明する。

## 変更

共通補足「新しいメッセージ」の末尾を、次のように変更する。

- 変更前：`前のやりとりはAIが覚えています。`
- 変更後：`同じ会話の続きなら、直前のやりとりを踏まえて答えてくれます。`

前半の操作説明は変更しない。

> 同じ会話の続きに、もう一度入力して送ります。新しい会話を始める必要はありません。

## 対象

- 正本：`js/view-model.js`
- 回帰テスト：`tests/view-model.test.mjs`
- 正本から生成する印刷版：`print.html`

画面構成、チャレンジ本文、README、CSS、保存データには変更を加えない。

## 完了条件

1. 画面の共通補足に新しい表現が表示される。
2. 旧表現「前のやりとりはAIが覚えています」が正本と印刷版に残らない。
3. `print.html` が生成器の出力と一致する。
4. 通常テストがすべて成功する。
