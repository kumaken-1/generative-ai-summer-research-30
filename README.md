# 夏休み限定　生成AI 夏の自由研究30

生成AIにまだ慣れていない小学校の教職員が、日常や学校の小さな困りごとを入口に「ちょっと使ってみよう」と思えるようになるための、30個のミニクエストです。夏休み中に公開し、気になるものを1個だけでも試せる場を目指しています。

## 参加のしかた

- 自由参加です。30回すべてを終える必要はありません。
- 順番も自由です。ただし、最初の10回は文字だけのやり取りを中心にし、生成AIとの対話に慣れられるようにしています。
- 11回目以降は、写真の撮影・画像の添付・文章の貼り付け・文書の添付を少しずつ体験します。
- ランキング、提出、成績評価はありません。取り組んだ数を競う企画でもありません。
- 生成AIを開けない場合も、入力例を読み「どんな返事が来そうか」を考えるだけで参加できます。

## 大切にしていること

生成AIの回答は「正解」や「完成品」ではなく、考えるための下書きです。回答を読んだら、自分の考え、好み、条件、違和感をもう一度伝え、対話を続けてください。

事実に関わる内容は、元の文書、公的機関の情報、別の信頼できる資料などでファクトチェックします。最後に採用するか、直すか、使わないかを決めるのは利用者自身です。

## プライバシーとデータ

- 児童・保護者・職員の氏名、顔、連絡先、成績、健康情報などの個人情報や、学校の機密情報を入力・撮影・添付しないでください。
- 練習には、架空の内容、公開済みの資料、個人を特定できない写真や文書を使ってください。
- このサイトには入力欄がなく、入力内容や生成AIの回答を収集しません。
- 進み具合とお気に入りは、利用中の端末の `localStorage` にだけ保存します。
- 外部API、アクセス解析、広告、トラッカーは使用しません。生成AIサービスとの通信もこのサイトからは行いません。

## 使い方

### GitHub Pages

公開後はGitHub PagesのURLをブラウザで開くだけで使えます。クエストを選び、「日常ルート」または「学校ルート」の入力例を、自分が利用できる生成AIサービスで試してください。

### ローカルで見る

このリポジトリを取得し、プロジェクト直下で静的ファイルを配信します。

```powershell
python -m http.server 4173
```

その後、`http://localhost:4173/` をブラウザで開きます。ビルドツールやAPIキーは不要です。

## 開発・確認

Node.js 22以降を想定しています。

```powershell
npm test
npm run build:print
npm run test:smoke
```

- `npm test`: 内容、状態保存、画面構造、公開文書のテスト
- `npm run build:print`: `js/quests.js` から印刷用の `print.html` を再生成
- `npm run test:smoke`: 利用可能な場合にブラウザで主要操作を確認

## 内容を更新する

クエスト本文の正本は [`js/quests.js`](./js/quests.js) です。更新後は `npm run build:print` を実行し、通常画面と印刷用ページの内容をそろえてから `npm test` を実行してください。生成済みの `print.html` だけを直接編集しないでください。

改善提案や誤りの報告は、公開リポジトリのIssueまたはPull Requestで歓迎します。実在する児童・保護者・職員や学校内部の情報は、Issue、Pull Request、サンプルデータ、画像のいずれにも含めないでください。企画の目的、初心者向けの言葉、既存の安全方針を保つ小さな変更を優先します。
