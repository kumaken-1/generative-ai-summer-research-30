# 生成AI 30のチャレンジⅠ

生成AIにまだ慣れていない人が、日常や仕事の小さな困りごとを入口に「ちょっと使ってみよう」と思えるようになるための、30個のチャレンジです。気になったものを、ひとつ試すところから始められます。

## 参加のしかた

- 自由参加です。30個すべてをやる必要はありません。
- 順番も速さも自由です。1日に何個やっても、間があいてもかまいません。
- ランキング、提出、成績評価はありません。取り組んだ数を競う企画でもありません。
- 生成AIを開けないときは、文章を読んで「どんな回答が来そうか」を考えるだけでも参加できます。

## 大切にしていること

生成AIの回答は「正解」や「完成品」ではなく、考えるための材料です。回答を読んだら、自分の考え、好み、条件、違和感をもう一言だけ返してください。採用するか、直すか、使わないかを決めるのは利用者自身です。

事実に関わる内容は、元の文書、公的機関の情報、別の信頼できる資料で確かめます。

## 1つのチャレンジの進み方

チャレンジをひらくと、次の順で並んでいます。**手順の番号は1回目から2回目まで通しで振ってあります。**

1. **1回目に送る** — 生成AIに送る文章と、そこまでの手順
2. **回答が来ます** — 何を見ればよいかを1行で書いています。ここがそのチャレンジのねらいです
3. **2回目に送る** — 空欄を自分の言葉でうめて、新しいメッセージとして送ります

添付や貼り付けが必要な回は、**添付と文章が同じメッセージで、送信は1回**であることを手順に明記しています。

## 操作の種類と色

「そのままコピーすればよいのか、自分で何か足すのか」が分かるように、操作の種類ごとに色とラベルを分けています。

| 色 | ラベル | 利用者がすること |
|---|---|---|
| 青 | そのままコピーして送る | コピーして貼り付けるだけ |
| 緑 | 自分の文を貼ってから送る | 自分で書いた文章を貼り付けてから送る |
| 紫 | 写真・資料を添付してから送る | 写真や資料を添付してから送る |
| 黄 | 空欄をうめてから送る | 文の空欄を自分の言葉でうめてから送る |
| 赤 | 注意 | この色は注意以外で使いません |

色は2番目の手がかりです。**ラベルとアイコンだけで何をするか決まる**ようにしてあるので、色の見分けが難しい人でも困りません。

## くわしく

初心者が実際に詰まる4か所にだけ、補足を用意しています。チャレンジごとに書き分けず、共通の4本を参照しています。

- 添付ボタンの場所
- 1回で送る
- 新しいメッセージ
- 貼り付け

補足は**押しても、マウスを乗せても開きます**。マウスのない携帯やタブレットでも読めるようにするためです。

## 記録

「やってみた」の印だけを、利用中の端末に保存します。件数や達成率、ごほうびの仕組みはありません。

## プライバシーとデータ

- 児童・保護者・職員の氏名、顔、連絡先、成績、健康情報などの個人情報や、機密情報を入力・撮影・添付しないでください。
- 練習には、公開済みの資料、個人を特定できない写真や文書、同梱の練習用素材を使ってください。
- 空欄をうめる入力欄がありますが、書いた言葉はこのサイトの外へ送らず、端末にも保存しません。画面を閉じると消えます。
- 「やってみた」の印だけを `localStorage` に保存します。入力内容や生成AIの回答は収集しません。
- 外部API、アクセス解析、広告、トラッカーは使用しません。生成AIサービスとの通信もこのサイトからは行いません。

### 練習用の素材

添付や貼り付けが必要なチャレンジでは、探す手間で止まらないよう練習用の素材を同梱しています。すべて架空の内容で、実在の学校・団体・人物とは関係ありません。

- `assets/sample-notice.md`：架空の通知文
- `assets/sample-draft.md`：架空のお便り下書き
- `assets/sample-screen.svg`：架空の案内画面

## 使い方

### GitHub Pages

公開後はURLをブラウザで開くだけで使えます。携帯にも対応しています。

### ローカルで見る

このリポジトリを取得し、プロジェクト直下で静的ファイルを配信します。

```powershell
python -m http.server 4173
```

その後、`http://localhost:4173/` をブラウザで開きます。ビルドツールやAPIキーは不要です。

## 開発・確認

Node.js 22以降を想定しています。

```powershell
npm test
npm run build:print
npm run test:smoke
```

- `npm test`: 内容、記録、画面構造、印刷用ページ、公開文書のテスト
- `npm run build:print`: `js/challenges.js` から印刷用の `print.html` を再生成
- `npm run test:smoke`: ブラウザで主要操作を確認

## 内容を更新する

チャレンジ本文の正本は [`js/challenges.js`](./js/challenges.js) です。更新後は `npm run build:print` を実行し、画面と印刷用ページの内容をそろえてから `npm test` を実行してください。生成済みの `print.html` を直接編集しないでください。

改善提案や誤りの報告は、公開リポジトリのIssueまたはPull Requestで歓迎します。実在する児童・保護者・職員や学校内部の情報は、Issue、Pull Request、サンプルデータ、画像のいずれにも含めないでください。
